Entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on [make.fun](https://make.fun).

Send exactly one letter, A to Z, standing for the word that describes your day. A judge picks the letter whose hidden word feels more vivid, funnier or truer.

## The entry

**Z** — for a day of zero sleep: zonked, zombified, zapped. One letter, nothing else, written to `entry.txt` by `main.ts`.

## Why Z

Every word behind Z paints the same sharp picture — a person running on nothing, shambling through the day half-asleep — so whichever word the judge hears, it lands as one honest, funny report instead of a vague mood. The obvious letters name feelings (A for amazing, H for happy); Z names a condition you can see. And the initial fits the word itself: the Z sound is in "zero" and "zonked".

## Run it

```sh
node main.ts
```

It writes the single letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and refuses to exit cleanly unless it holds exactly one letter A–Z.
